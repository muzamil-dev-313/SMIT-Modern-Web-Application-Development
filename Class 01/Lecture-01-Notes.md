📖 Lecture 01: Introduction to HTML
What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure web pages. It provides the basic framework of a website by organizing content such as text, headings, images, lists, tables, and forms.

Basic Structure of an HTML Document

Every HTML document consists of two main sections:

1. Head Section

The <head> element contains information about the webpage that is not directly displayed on the page.

Example:

<head>
    <title>My First Web Page</title>
</head>
2. Body Section

The <body> element contains all the visible content displayed in the browser.

Example:

<body>
    <h1>Welcome to HTML</h1>
    <p>This is my first webpage.</p>
</body>
Common HTML Elements
Headings

HTML provides six levels of headings:

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
Paragraph

The <p> tag is used to create paragraphs.

<p>This is a paragraph.</p>
Bold Text

The <b> tag displays text in bold.

<b>Bold Text</b>
Italic Text

The <i> tag displays text in italic style.

<i>Italic Text</i>
Line Break

The <br> tag creates a new line.

Hello<br>World
Horizontal Rule

The <hr> tag inserts a horizontal line.

<hr>
Lists
Unordered List

Displays items with bullet points.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
Ordered List

Displays items in numbered format.

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
Attributes

Attributes provide additional information about HTML elements.

Example:

<a href="https://www.google.com">Google</a>

Here, href is an attribute.

Comments

Comments are used to add notes within the code and are not displayed in the browser.

<!-- This is a comment -->
Opening and Closing Tags

Most HTML elements consist of:

Opening Tag
Content
Closing Tag

Example:

<p>This is a paragraph.</p>

Some tags do not require closing tags, such as:

<br>
<hr>
